# Property

|Name|
|-|
|Item|
|Tone|
|Index|
|TitleFontSize|
|BodyFontSize|

# Example

```xml
<dev:ScrollSplitCardPanel Item="{x:Bind Card}" Tone="Chart" Index="0" />
```

> [!NOTE]
> `ScrollSplitCardPanel` is normally created by [ScrollSplitCard](../ScrollSplitCard). With the `Chart` tone, `Index` selects one of three palettes and wraps around.
